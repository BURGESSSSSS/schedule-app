# CSV 导入格式

## 文件要求

- 文件编码使用 UTF-8
- 第一行必须是表头
- 每一行代表一条重复课程
- 字段之间使用英文逗号分隔
- 如果字段内容包含逗号，需要按照标准 CSV 规则使用双引号包裹

## 表头

```csv
课程名称,教师,教室,星期,开始时间,结束时间,开始周,结束周,单双周,提醒分钟
```

## 示例

```csv
课程名称,教师,教室,星期,开始时间,结束时间,开始周,结束周,单双周,提醒分钟
高等数学,张老师,A101,1,08:00,09:40,1,16,全部,10
大学英语,李老师,B203,2,10:00,11:40,1,16,单周,15
程序设计,王老师,实验楼302,3,14:00,15:40,2,16,双周,5
```

## 字段规则

- `课程名称`：必填
- `教师`：可以为空
- `教室`：可以为空
- `星期`：必填，使用 `1` 到 `7`，其中 `1` 表示周一，`7` 表示周日
- `开始时间`、`结束时间`：必填，格式为 `HH:mm`
- `开始周`、`结束周`：必填，正整数，且开始周不能大于结束周
- `单双周`：只能填写 `全部`、`单周` 或 `双周`
- `提醒分钟`：填写 `0` 表示关闭该课程提醒，或填写不小于 `0` 的整数

## 导入行为

导入时先校验全部内容。只要有一行错误，就不写入数据库，并显示错误行号和原因。
