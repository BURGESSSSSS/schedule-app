1. 大白话总结：在「更多」加入「课表导入教程」，分六步说明无线调试、企业微信课表准备、逐周采集与预览导入；页末「开始导入」直接进入现有学校课表同步页面。「更多」支持滚动，新增入口在小屏上也能查看。

3. 自查：§7.1 中颜色、唯一黑色主操作、无阴影/渐变/模糊/装饰图标、设计常量满足；现有课程逻辑、数据库与导入逻辑未改；§5.3 课程详情转场全部未改。教程采用已有子页骨架和卡片；进入/退出使用 Motion 动效常量并尊重系统关闭动画。
4. 验证：:app:assembleDebug 通过。真机和模拟器视觉验证尚待阶段二完成后进行。
5. 偏差：沿用当前项目固定浅色主题，不额外增加深色模式；教程为完整文字步骤，使用者尚未提供截图，因此未放置占位图片。此次不是整套界面改版，不重复 DESIGN_BRIEF.md 的原八阶段。
6. 验收：更多 → 课表导入教程 → 可滚动查看六步及常见问题；滚动到底部 → 开始导入 → 出现学校课表同步；返回 → 更多；小屏/放大字体 → 内容仍可滚动阅读。

## 阶段二：首次欢迎与快捷入口

1. 大白话总结：首次使用时显示欢迎介绍，提供「查看导入教程」「直接导入」「先逛一逛」。关闭或选择入口后保存确认状态，后续启动和升级不重复弹出；未确认时旋转屏幕仍保留欢迎提示。底部联系文案为「使用过程中遇到问题，或有任何改进建议，欢迎通过邮箱联系开发者：suyu20651@gmail.com」。邮箱可点击复制并显示反馈。小屏及大字体时介绍区域可滚动，操作按钮与联系区域保持可见。
2. 改动文件：ui/onboarding/WelcomeDialog.kt、ui/app/ScheduleApp.kt、ui/theme/Shape.kt、ui/more/MoreScreen.kt、res/drawable/symbol_menu_book.xml、assets/licenses/SOURCES.md、androidTest/ui/onboarding/WelcomeTutorialFlowTest.kt。新增图标来自现有 Material Symbols Rounded 400 系列，保留 Apache 2.0 许可。
3. 首次状态保存：独立的 onboarding SharedPreferences，仅在用户关闭/选择入口时写入 welcome_seen；本项目禁用系统应用数据备份，全新安装的初始状态会显示欢迎。旧版本用户尚无确认记录时也会看到一次欢迎。分享课表截图时，先展示欢迎，再处理待导入图片，避免窗口互相遮挡。

### 偏差及取舍

- 无新增设计风格偏差。沿用现有固定浅色主题；深色模式属于当前项目未开放的功能，本次不扩展。
- 仅做本次请求的两个阶段，不重新实施整套改版，也不增加 §11 可选增强。
- 首次欢迎没有点击来源卡片，因此使用标准模态窗口。白色圆角面板、40% 遮罩、无描边无阴影，沿用现有按钮反馈；教程使用与现有子页面一致的轻量水平位移和淡入。

### 真机验收清单

1. 首次打开新安装的课程表 → 查看欢迎 → 应出现架构、学校定制及无线调试导入说明。
2. 欢迎 → 查看导入教程 → 应进入教程；滚动到末尾 → 开始导入 → 应进入学校课表同步。
3. 欢迎 → 直接导入 → 应直接进入学校课表同步；返回 → 应回到更多。
4. 欢迎 → 点击邮箱 → 应显示「邮箱已复制」；关闭欢迎并重启 → 不再重复弹出。
5. 更多 → 课表导入教程 → 可反复查看全部步骤及常见问题。
6. 将字体调大 → 打开首次欢迎 → 按钮、邮箱仍可见，正文可滚动；教程和更多内容均可滚动，不遮住底部导航。
