# 课程表 1.3.6

首次在 GitHub 提供正式签名的 Android 安装包。

本版本完善周视图中的课程名称、完整地点与换行显示，并加入课程表文件备份与恢复。备份文件打开后可先预览信息，再选择合并或恢复。

现有功能包括今日课程、周视图、手动课程管理、OCR 课表识别、学校课表导入、课程提醒和开发日志。

## 下载与安装

- 最低支持 Android 7.0（API 24）。
- 在下方 Assets 中下载 `schedule-app-1.3.6.apk`，在手机上打开安装。
- `Source code (zip)` 和 `Source code (tar.gz)` 是源码，不是安装包。
- 与已有版本使用同一签名时，可以覆盖升级；如果手机提示签名不一致，请先在旧版中备份课程数据，再处理旧版安装。

`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。
