# 课程表 1.3.7

这是本轮开发的收尾版本，为山东商务职业学院学子定制。

## 本次更新

- 首次使用显示欢迎介绍，可查看导入教程或先逛一逛；邮箱点击即可复制。
- 「更多」新增课表导入教程，说明无线调试配对、企业微信教务课表准备、逐周采集、检查结果和确认导入。
- 欢迎文字统一居中，开发日志补齐并与项目文档同步。
- 归档历史开发资料，清理无用演示代码，整理最终源码与安装包。

已有的今日课程、周视图、截图识别、手动编辑、学校课表导入、课程提醒及备份恢复继续保留。

## 下载与安装

- 在 Assets 中下载 `schedule-app-1.3.7.apk`，在 Android 手机上打开安装。
- 最低支持 Android 7.0；学校课表导入需要 Android 11 或以上及无线调试功能。
- 使用与 1.3.6 相同的正式签名，可以覆盖升级并保留应用数据。
- `Source code` 压缩包用于开发，不是安装包。
- `SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。
