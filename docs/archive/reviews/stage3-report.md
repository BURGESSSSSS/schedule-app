# 阶段 3：今日页

## 1. 大白话总结

首次使用时，“还没有课程”和导入/添加按钮放在页面中间。有课时仍保留一条时间线，每节课只出现一次；没课时下一节的日期和倒计时分两行，避免三个信息挤成一串。进度条只在进入时填充一次，之后按分钟更新，不再每分钟重播动画。离开课表页面、打开覆盖层或应用退到后台时停止定时刷新，返回时立即校准时间。

- `app/src/main/java/com/burgess/schedule/MainActivity.kt`：可见性控制、居中空状态、元信息排版、单次进度动画；缓存课程 UI 映射并标记不可变；保留取件码入口。
- `app/src/main/java/com/burgess/schedule/ui/today/TimelineState.kt`：提取次日剩余课程和安全进度计算。

## 4. 偏差及原因

- §4.2 的没课标签示例包含三段信息，与 §2.3 每行最多两段冲突；按设计哲学优先，将“下一节 · 明天 08:00”和倒计时分两行。
- 周视图也需要更新正在上课的标记，因此当周视图可见时共享时钟仍运行；今日页本身离开后不再计算/绘制倒计时。更多页和覆盖层打开时停表。
- 保留原有待取件码入口，没有为了空状态隐藏既有功能。

## 5. 真机检查

1. 没有课程时打开今日 → 查看中间 → 应看到导入与手动添加按钮，不靠顶部堆放。
2. 有正在上课的课程时打开今日 → 上下滚动 → 该课程只出现一次，只有它是重点卡片。
3. 停留至下一分钟 → 进度应更新，但不重新从头填充；切到更多再返回 → 时间立即校准。
4. 今天没课、明天有多节课 → 查看下一节和下面列表 → 第一个课程不重复，日期和倒计时分行。
5. 今日课程全部结束 → 保留今日列表，出现结束说明和下个有课日预览；已结束文字变灰，整卡不透明化。
