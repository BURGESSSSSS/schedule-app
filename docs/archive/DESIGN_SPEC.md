# 界面设计规范

## 1. 整体感觉

关键词：清爽、安静、易读、适合每天打开。

课程表是高频工具，不做营销式首页，不堆装饰，不使用大面积渐变。信息优先，颜色用于区分课程和状态。

## 2. 首页结构

首页从上到下：

1. 当前日期和当前周次
2. 上一周、回到本周、下一周
3. “下一节课”简要信息
4. 周视图课程网格
5. 空状态或错误提示

打开应用后直接进入课程表，不先展示介绍页或登录页。

## 3. 课程视觉

- 不同课程使用少量稳定的颜色区分
- 普通课程使用低饱和背景色
- 下一节课使用清晰的边框和强调色
- 正在进行的课程使用更明显的状态标识
- 文字优先显示课程名称，教师和教室作为次要信息

## 4. 交互

- 点击课程进入编辑
- 点击空白时间段进入添加课程
- 长按课程提供编辑和删除
- 导入流程必须先预览，再确认
- 删除操作需要二次确认
- 默认周视图保持周一至周五五列；目标周有周末课程时，周六日使用独立两列网格显示，保证常规五列的可读宽度
- 页面和周切换使用短暂、轻量的位移动画；不使用常驻动画或实时模糊

## 5. 小屏适配

- 课程格子的行高按可用视口预算，超出屏幕时由周视图自然滚动
- 课程名称和教室按格子实际高度分配行数，允许自然换行；短节次才截断
- 教室优先保留更多行，详情面板始终展示完整地点和时间
- 主要操作在单手可触达区域内
- 课程编辑表单可滚动，键盘出现时保存/取消仍保持可达

## 6. 可行性目标

“秒打开”作为体验目标，而不是绝对承诺。应用采用本地数据、无登录、无网络请求，启动时只读取当前周课程，避免首次打开时加载无关数据。最终速度要在模拟器和至少一台真实 Android 手机上测试。
