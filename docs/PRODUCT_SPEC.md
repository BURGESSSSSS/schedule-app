# 产品功能规格

## 1. 产品定位

一个离线、轻量、容易使用的 Android 课程表工具。

## 2. 用户

主要用户是需要查看学校课程安排的学生。用户不需要注册账号，也不需要联网才能查看课程。

## 3. 第一版功能

### 3.1 周视图

- 显示周一到周日
- 显示当天各时间段的课程
- 支持上一周、下一周和回到本周
- 显示课程名称、教室和教师

### 3.2 课程管理

每条课程至少包含：

- 课程名称
- 教师
- 教室
- 星期
- 开始时间
- 结束时间
- 开始周
- 结束周
- 全部周、单周或双周
- 是否开启提醒
- 提前提醒分钟数

### 3.3 当前课和下一节课

- 如果当前时间处于某节课的开始时间和结束时间之间，标记为“进行中”
- 否则高亮当天之后最近的一节课
- 如果当天没有后续课程，则高亮下一次有课日期中的第一节课
- 学期之外的课程不参与计算

### 3.4 通知提醒

- 用户可以设置默认提前提醒时间
- 用户可以为单节课程关闭提醒
- 通知内容包含课程名称、教室和上课时间
- 首次使用提醒功能时，需要处理系统通知权限
- 不提供独立的闹钟页面、响铃、贪睡和闹钟列表
- 第一版接受通知可能有少量延迟，并在设置页明确提示
- 提供“发送测试通知”，方便用户确认权限和系统设置

### 3.5 导入课程

- 第一版支持 UTF-8 CSV
- 导入前显示预览
- 发现错误时显示具体行和字段
- 校验通过后一次性导入，避免只导入一半
- 导入格式见 [IMPORT_FORMAT.md](IMPORT_FORMAT.md)

## 4. 暂不实现

- 用户账号
- 云端同步
- 多人共享
- 自动从学校教务系统抓取
- XLSX 导入
- 桌面小组件
- 课程评价和社交功能

## 5. 验收标准

当以下场景都能成功完成时，第一版核心功能算完成：

1. 新用户打开应用后可以设置学期开始日期
2. 新用户可以手动添加一节课程
3. 课程能出现在正确的星期和时间位置
4. 用户切换到下一周时，课程显示和周次规则正确
5. 当前课或下一节课有明显但不刺眼的高亮
6. 用户导入合法 CSV 后，课程能出现在课程表中
7. 用户导入错误 CSV 时，应用能指出错误，不破坏已有课程
8. 用户允许通知权限后，可以收到测试提醒

## 6. 重要边界

课程提醒不是医疗、交通或考试倒计时等强实时功能。第一版优先保证实现简单、耗电较少和容易维护，因此不承诺通知在设定时刻精确到秒。
