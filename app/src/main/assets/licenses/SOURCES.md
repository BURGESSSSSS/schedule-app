# Bundled design assets

- Inter 4.1: https://github.com/rsms/inter/releases/tag/v4.1
  - Unmodified static `Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-SemiBold.ttf` from `extras/ttf` in the official release archive.
  - SIL Open Font License, bundled as `Inter-OFL.txt`.
- Material Symbols Rounded, default 400 weight, 24px:
  https://github.com/google/material-design-icons/tree/master/symbols/web
  - SVG paths converted directly into Android VectorDrawable XML; no path changes.
  - chevron_left, chevron_right, notifications, inventory_2, palette, speed, history, mail, content_copy.
  - Apache 2.0 license bundled as `Material-Symbols-Apache-2.0.txt`.
